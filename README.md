# Gerador de proxy

Este é um script que cria um gerador de proxys. Use-o em uma VPS.

Sinta-se a vontade para usar ou modificar.

### Instalação

```bash
curl -O https://raw.githubusercontent.com/luannsr12/proxy_generator/main/setup.sh
chmod +x setup.sh
./setup.sh
```
